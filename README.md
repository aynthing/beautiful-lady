# Hey Beautiful — Responsive Website

A clean, mobile-first recreation of the supplied Instagram Reel's visual concept.

## Run
Open `index.html` in any modern browser.

## Included
- Responsive mobile/desktop layout
- Dark black/pink neon visual style
- Animated heart landing screen
- Animated 120% cuteness meter
- Interactive compliment buttons
- Note card
- Ending screen
- Reduced-motion support
- No build tools required

You can replace the text in `index.html` to personalize the message.
